# からだ記録（Android 用ヘルスケアアプリ）

女性の健康管理と歩数計測を最優先にした Flutter 製アプリです。データはすべて端末内に保存され、外部には送信しません。

## 機能

- **歩数**（最初に開く画面）: 端末の歩数センサーで今日の歩数・目標達成率・距離・消費カロリー目安・直近7日グラフ
- **周期**: 月経開始/終了の記録、次回月経・排卵日・妊娠しやすい期間の目安、カレンダー表示、履歴
- **記録**: 基礎体温（30日グラフ）、気分、症状、メモ。カレンダーの日付タップでも記録可能
- **設定**: 歩数目標、毎日の記録リマインド、月経予定日2日前の通知

## APK の作り方

### 方法A: GitHub Actions（PC に開発環境が不要・おすすめ）

1. GitHub で新しいリポジトリを作り、このフォルダの中身を `main` ブランチに push する
2. リポジトリの **Actions** タブ → **Build APK** → 完了を待つ（初回は10分前後）
3. 実行結果ページ下部の **Artifacts** から `karada-log-apk` をダウンロードして解凍すると `app-release.apk`
4. APK を Android 端末に送り、「提供元不明のアプリ」のインストールを許可して開く

### 方法B: 自分の PC でビルド

1. Flutter 3.24.5 と Android Studio（Android SDK 同梱）をインストール
2. このフォルダで次を実行（Mac / Linux / WSL。Windows のコマンドプロンプトでは `tool/patch_android.py` を `python` で実行）

```bash
bash tool/setup.sh              # 初回のみ: android/ を生成して設定を追加
flutter build apk --release
# → build/app/outputs/flutter-apk/app-release.apk
```

## 注意

- 作成環境ではビルドできなかったため、**未コンパイル・未実機確認**です。ビルドでエラーが出た場合はログをそのまま共有してください。
- リリース APK は Flutter 標準のデバッグ署名です。Google Play に公開する場合は、別途ご自身の署名鍵が必要です。
- 歩数は端末起動以降の累積センサー値から日別に算出します。初回起動時点より前の歩数は含まれません。
- 通知時刻は日本時間（Asia/Tokyo）固定です。
- 月経・排卵の予測は過去の記録からの目安で、診断や避妊の目的には使えません。
